Pendências para decidir antes do visual

  1. E3 hoje é o choque de horário na T3, não vaga esgotada (ver criterios-do-projeto.md). O wireframe propõe E3 como vaga esgotada na T2 e deixa o choque como variante da T3. Nenhuma disciplina tem 0 vagas nos dados, então seria preciso uma disciplina demonstrativa esgotada.
  2. Grid de 4 colunas é novo. O design-system.md fala em uma coluna. Se aprovado, entra como decisão e muda a linha de grid da tabela.
  3. "Cancelar" na T3 precisa de diálogo de confirmação (Esc devolve o foco) para não apagar a seleção sem querer.
  4. Lista de espera no E3 é uma função nova. Se não entrar, a saída fica só "ver outras turmas".
